# Country guide gap fill — November 5, 2026

This batch fills the 56 country/topic gaps listed in the November 5 publication report. The facts were added to `public.travel_facts` as published records; the app’s front end was not changed.

## Review approach

- Wrote each fact in concise, practical language for U.S. travelers, using the same direct, qualified tone as the existing guides.
- Used government, border, transport, telecom, tourism, and recognized electrical-safety sources where available. Each fact links to the source material and records its review date and scope.
- Limited each paragraph to claims supported by its listed sources. Regional and provider-specific facts say where they apply; changing terms and schedules are directed back to the operator or authority.
- Kept sensitive and uncertain guidance cautious. The Iraq records retain the current U.S. “do not travel” advisory; Saudi customs text does not state a cash threshold because the authority’s public pages show different values.

## Coverage

`facts.json` contains the 56 records in this batch. After publishing, `../publication-2026-11-05/coverage-gaps.json` has no remaining gaps among the country/topic pairs in the previous report. This means each listed topic has at least one published fact; it does not mean each country has a complete guide.

Database verification after the write: 263 published facts across 24 destinations, including 56 new records in this batch. These destinations use 23 country codes because England and Scotland share GB. Read the [formatted country guides](../country-guides/README.md) for the complete published collection.
